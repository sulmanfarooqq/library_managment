# MUST Smart Library — Frontend Prototype

A multi-page frontend prototype for a **smart university library experience**, designed around student access, discovery, book details, and an AI-assisted academic interface.

## Pages

1. **Student Login** — institutional sign-in interface
2. **Student Dashboard** — academic overview, recommendations, and department filters
3. **Library Landing Page** — smart-library product presentation and feature overview
4. **Book Details** — book metadata, availability, insights, and recommendations
5. **AI Academic Chat** — conversational academic-assistance interface

## Highlights

- Responsive layouts for desktop, tablet, and mobile
- Semantic HTML structure
- Component-like reusable CSS patterns
- Interactive login password visibility control
- Modern dashboard and library UI concepts
- Separate HTML/CSS files for easy learning and modification

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

No frontend framework is required.

## Project Structure

```text
├── must_student_login/
├── must_student_dashboard/
├── must_library_landing_page/
├── must_book_details_page/
└── must_ai_academic_chat/
```

Each page contains its own HTML and CSS implementation.

## Run Locally

No build step is required. Open any page's `index.html` in a browser, or serve the repository with a local static server.

## Scope

This repository is a **frontend prototype**. Authentication, database operations, AI services, and production backend workflows are not connected.
